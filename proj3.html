Project 03 · Secure Software Delivery Pipeline
DevSecOps Pipeline with Software Supply Chain Controls
OwnBackup · Product Security Team Leader · 2021
Zero critical vulns in prod · 40% faster releases
Stack
Sonatype Nexus Firewall Snyk SCA SonarQube SAST Container images scaning Burp Suite DAST GitHub Actions
Challenge

Engineers bypassed security by pulling packages directly from the internet and merging code without consistent AppSec gates. We needed a secure software factory that controlled the entire software supply chain—from package intake to production deployment—while maintaining developer velocity.

Security Domains & Risk Coverage
Software Supply Chain Security
  • Protected Nexus repository as single source of truth for all OSS packages
  • Pre-ingestion scanning to block malicious/vulnerable components
Code & Dependency Security
  • SonarQube SAST for code vulnerabilities & quality gates
  • Snyk SCA for OSS dependencies, transitive vulns, license compliance
Container Security
  • Kubernetes image vulnerability scanning at merge time
  • Runtime container misconfiguration detection
Application & API Security
  • Burp Suite DAST on candidate branches for web/API vulnerabilities
Risk Governance
  • Automated severity-based Jira ticketing with SLAs
  • Pragmatic merge policy (fail only criticals, track everything)
Implementation
Pipeline 1 – Secure Package Factory (Nexus)
  • Enforced all OSS packages route through internal Nexus Repository Firewall
  • Blocked direct npm/pypi/maven pulls from public registries
  • Pre-scanned every package before allowing consumption in builds
Pipeline 2 – AppSec Merge Gates
  • Integrated SAST (SonarQube), SCA (Snyk), K8s image scanning at merge
  • Auto-created Jira tickets for all new vulns with team assignment
  • Hard fail policy: Critical only → High/Medium tracked via SLAs
  • DAST layer: Burp Suite on candidate branches for API/web issues
